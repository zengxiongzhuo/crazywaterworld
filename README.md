在本机管理《疯狂水世界》账号，直连游戏 WebSocket，安排领奖、基地经营、英雄养成和舰队任务。每个账号独立保存开关、详细配置和用量记录，运行日志会说明实际完成的操作、收益及跳过原因。

## 快速开始

需要 Windows，建议使用 Node.js 22.12 或更高版本；同时兼容 Node.js 20.19+（20.x）。请先在电脑版微信中打开一次《疯狂水世界》，供工具读取本机游戏协议包。配置表和世界地图默认从游戏 CDN 自动更新。添加抖音账号需要登录本机电脑抖音，再从客户端打开游戏供工具采集。支付宝扫码首次使用时会自动下载与 Playwright 版本匹配的 Chromium（需服务器可访问下载源并预留磁盘空间）；已有浏览器可继续复用，也可通过 `CW_BROWSER_EXECUTABLE` 指定。

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
npm ci
npm start
```

默认控制台地址为 `http://127.0.0.1:17321/`。

1. 进入 **账号 → 添加账号**，在弹窗中选择支付宝、益世界 APP、电脑微信或电脑抖音采集，按步骤完成登录。微信、抖音提示正在读取后，从对应客户端重新进入游戏。APP 可使用账号密码或短信验证码，从列表中选择区服和游戏角色并保存；首次生成设备档案时随机选择预设机型及配套 Android 版本，保存后持续复用。[APP 登录步骤](docs/console-guide.md#手机号登录)
2. 新账号保存后默认不挂机。在 **挂机配置** 调整所需模块，再点击账号卡片或页头的 **开始挂机**。账号卡片可直接开始或暂停对应账号的挂机，无须先切换账号。**暂停挂机** 后保留游戏连接，可继续使用控制台的手动操作。页头按钮左侧的间隔按账号自动保存，运行中修改后下一轮生效。
3. 在 **挂机配置** 设定项目、资源保留和预算，可用 **只读预览** 查看当前计划。**世界 → 舰队调度** 支持拖动行首手柄调整任务顺序，松开后自动保存，也可使用上移／下移按钮。点击 **开始挂机** 后持续循环，直到手动点击 **暂停挂机**。
4. 挂机开始后可关闭网页，请保持启动窗口打开、电脑唤醒。关闭启动窗口或按 `Ctrl+C` 会结束进程。

支付宝渠道账号可在 **账号 → 添加账号 → 支付宝** 点击 **生成二维码**，用支付宝扫码确认，从列表中选择游戏角色和区服，点击 **保存所选角色**。新账号保存后等待用户手动开始挂机，已有账号沿用保存的自动挂机选择。账号列表显示所选角色名称与区服。二维码来自玩一玩游戏页面，临时浏览器会在读取到登录凭证后关闭。[支付宝扫码步骤](docs/console-guide.md#支付宝扫码登录)

抖音渠道仅保留 **账号 → 添加账号 → 电脑抖音采集**：先登录本机电脑抖音，采集就绪后重新打开《疯狂水世界》，等待工具保存登录信息并完成清理。抖音扫码登录及控制台内手动验证已移除：扫码后可能还会出现二步验证，流程过于复杂、操作麻烦，不建议接入。[电脑抖音采集步骤](docs/console-guide.md#电脑抖音采集) · [扫码研究归档与抓包方案](docs/douyin-login.md)

手动进入游戏操作时，按 **暂停托管 → 进入游戏操作 → 退出游戏 → 恢复托管** 执行，恢复时按已保存的间隔持续运行。自动重连和接管时的生产同步规则见使用指南。[持续运行与自动恢复](docs/console-guide.md#持续运行与自动恢复)

> 请只用自己的账号测试。自动化操作会改变游戏内的资源和进度，使用第三方工具有账号处罚风险。电脑微信或电脑抖音采集会临时更改当前 Windows 用户的代理和证书设置。账号凭证与账号导出文件含登录信息，请留在本机。

已配置账号的 `data/automation-settings.json` 或对应账号配置被删除、损坏时，控制台会停止挂机并关闭自动启动，恢复全部关闭的默认配置并提示重新配置。损坏原文件会先备份为同目录的 `.corrupt-*.bak`；正常账号配置、登录凭据与消费账本不会重置。运行中的配置变化也会被检查，旧页面草稿不会自动覆盖恢复结果。重新载入、配置并保存后，需要手动开始挂机；未来版本或无法读取的文件只报错并停止执行，不擅自覆盖。首次添加账号尚未保存配置不算损坏，正常版本升级仍走配置迁移。

后台更新或重启后，旧网页会提示刷新并暂停自动保存。页面加载时固定的版本会随请求发送，后台拒绝过期页面或未携带版本的旧网页写入；不能仅靠读取最新接口版本继续保存。未保存草稿保留在原页面，可先下载游戏配置草稿或复制其他修改，再刷新；停止挂机和断开连接仍可用。配置修订号同时检查，刷新后的页面也不能覆盖另一页刚保存的修改。

## 功能一览

页面按 **总览 / 挂机成果 / 挂机配置 / 建筑一览 / 挑战 / 阵容 / 活动 / 杂项 / 账号** 分组。杂项包含联盟、仓库、英雄与装备和礼包兑换，默认打开联盟。账号页每张卡片上的「登录设置」可独立配置该账号的自动重连、重连延迟、随机偏移、深夜空窗期和重试上限；点击「保存设置」仅保存到该账号，无需切换当前账号。页头分别控制挂机启停、托管暂停与恢复，并可调整挂机间隔。各模块的挂机开关统一放在对应挂机配置顶部，细项、策略、消费权限和参数可在同页调整并自动保存；关闭模块保留原有选择。挂机配置分为基地、世界、英雄、藏品、装备、日常与活动六个分类。新账号的挂机、模块和配置细项开关全部默认关闭，包括免费领奖和自动重连；请按需逐项配置并开启，再开始挂机。已保存的开关选择会保留，重新获取同一账号凭据不会重置配置。

**挂机成果**展示本次挂机和北京时间今日累计的在线时长、已完成操作、收获、消耗及明细，可按当前区服或同账号全部区服查看。轮换切区和普通重连继续累计，停止后保留战报，重启接续记录。奖励回包与资产推送去重；收获与消耗分别累计，不将任务预览奖励或整包库存算作成果。新版本启用后开始记录，不补算历史日志。[统计口径](docs/console-guide.md#挂机成果)

“挂机配置 → 日常与活动”中，“任务与领奖”排第一，“周期活动”排第二。剿匪榜达标奖励、杀敌榜达标奖励、新手七日登录奖励、漫剧观看与每日奖励、擂台赛每日礼包和赛季宝箱用钥匙开启统一在“任务与领奖”设置，保留各自独立开关；移除独立的“限时活动”和“漫剧 · 擂台赛 · 赛季宝箱”页签，其余联动奖励在活动开放时归入“限时 · 联动系列”。

海上风采大赛是限时活动，自动挂机、每日投票和每日礼包开关统一在 **活动 → 海上风采大赛** 的期次详情中设置，保留原账号选择。挂机配置不再保留固定页签；活动页按服务器下发的期次展示，未开放与已结束期次默认收起，执行仍受活动起止时间限制。

万吨巨轮统一在“挂机配置 → 世界 → 万吨巨轮”设置，日常分类中的旧派遣开关已停用；已有世界配置保持原值，关闭巨轮总开关后不会回退到旧入口派遣。

**总览 → 资源田概览**按汽油、种子、科技点汇总数量与有效基础时产，明细默认折叠。管理弹窗用已占和可占两张表查看田地，已占田可逐行替换或单独放弃；单独放弃不要求空闲舰队或汽油。占领与替换在确认页核对产量、费用和舰队；替换会先放弃指定旧田，新田出征或战斗失败不会恢复旧田。**挂机配置 → 世界 → 资源田**可设置优先资源、参与舰队、最低耐久、保留空闲舰队、最低田地等级及检查间隔。自动化默认关闭，按偏好优先选高产田，每次检查最多派一队，只补名额、不自动换田；服务器拒绝或出征返航后未确认占领时，当日暂缓自动占田。[玩法与策略说明](docs/resource-fields.md)

海盗扫荡与首杀统一在 **挂机配置 → 世界 → 海盗讨伐** 设置。“每日免费扫荡”使用所选种类已首杀的最高等级，无需舰队或汽油；“自动讨伐首杀”派遣舰队挑战下一等级，消耗汽油。两个开关独立，可同时开启，原有设置保留。

**联盟城战逐队加速**位于“挂机配置 → 世界 → 联盟城战”，分别设置每队维修／派遣加速、剩余时间阈值和每日钻石上限，不设单次维修或整段航程钻石上限。维修与派遣各有独立的智能省钻开关和等待上限，可只关闭维修省钻、保留派遣省钻。维修在2:01这类计费边界短等至1:59；每次任务最多短等一次，默认最多5秒，关闭则只按时间目标及预算执行。确认加速后快速复查，维修补满后同轮检查城战派遣。每队维修、派遣的每日用量独立计数，同时遵守“基础 → 加速与钻石”中的全局每日钻石预算；加速默认关闭，0预算禁止消费。加速总开关位于参与舰队之前，逐队设置显示尚未生效的开关或零预算，并可直接定位修改。一级配置分区默认展开，二级及更深参数默认收起，按需展开。切换模式或开关后会清除旧草稿的校验提示，再按当前配置校验。世界配置和挂机世界入口将联盟城战、万吨巨轮、硅矿置前；舰队选择只显示服务器确认已建成的队伍。攻守目标策略分区并提供跳转。普通战后维修短时复查，区分“已开始维修”“已补满”“仍待确认”。

维修和派遣加速还须开启舰队名单上方的“维修及派遣钻石加速总开关”及资源页的钻石消费开关；各项钻石上限须大于 0。逐队设置会显示未生效原因并提供跳转，联盟城战预览也会提示加速总开关关闭。

维修费率由所有舰队及玩法共享；城战、硅矿统一跟踪累计分钟，防止推送迟到造成跨档低估费用。行军每次回读后判断，在最后接近目标时短等省掉一次固定费用。[协议分析与省钻示例](docs/fleet-speed-protocol.md)。

页头账号选择框使用紧凑宽度和彩色状态标签，展开后显示全部账号的名称及完整状态，长名称自动换行。支持方向键选择、回车确认和 Esc 关闭。页面可见时每 3 秒刷新，打开列表时也会重新读取。手机端页头提供挂机、托管和日志入口。**暂停托管** 会停止任务、断开连接并持久保存状态，退出游戏后可恢复托管。

运行日志默认汇总全部账号，提供带计数的分类 Tag：系统灰色、基地与资源绿色、世界与联盟蓝色、日常与活动紫色；警告与错误另用黄、红 Tag。每条日志显示账号名称，内部 ID 仅保留在悬停提示中，同名账号用序号区分；分类与账号各用一排带计数的 Tag，可组合筛选分类、账号及警告/错误。分类与账号 Tag 始终单行显示，超出宽度可左右滑动，长账号名单行省略；点击或键盘切换后选中标签自动进入可见区域，实时日志更新保留滑动位置。点击日志中的账号 Tag 也可直接筛选，不再保留重复的功能下拉框。筛选独立于页头账号，切号不清空记录；清空只影响选定账号。终端输出包含时间、账号名称、中文功能类型和日志等级。

账号页按区服角色分别展示卡片，包含区服、角色、渠道、等级、战力和资料更新时间；页头选择器也按区服角色展开。点击 **刷新区服** 可读取各登录账号已有的角色，APP／支付宝保存角色时会一并保留该账号的其他区服。同一登录账号只能有一个区服在线：切换或开始其他区服挂机时，先停止旧角色任务和重连、恢复必要阵容并关闭旧连接，再登录目标区服；登录失败时尝试恢复原区服。各区服的配置、阵容、用量和运行状态独立保存，新增角色默认不挂机，重启只恢复该账号选中的区服。合服角色保留原区服入口与当前区服的对应关系。旧账号及其配置原位保留，备份支持导入、导出多个区服角色。卡片菜单可修改备注、导出或移除对应角色。登录预览中的手机号使用掩码，账号备份文件含完整登录凭据，请妥善保管。

**区服轮换挂机**位于账号页。选择登录账号，勾选参与角色、调整顺序并填写每个区服的挂机分钟数，再启用每日轮换并保存。例如设置 **23:00–06:00**，区服 A 30 分钟、B 20 分钟、C 10 分钟，会在北京时间每晚 23 点开始，按 A → B → C 循环，到次日 6 点停止任务并断开连接。每个角色使用自己的挂机配置；时长从登录完成后计算，运行时段结束时提前停止。支持全天轮换、暂停和继续；手动切区或控制挂机会暂停该账号轮换，点击 **继续轮换** 后接管。窗口内重启继续当前角色剩余时间，窗口外重启等待下次时段，各登录账号独立轮换。网络波动或心跳超时默认间隔 **10 秒**、最多重试 **3 次**，可在轮换配置中调整或关闭；重连保留原交接时间，次数用完后尝试下一区服。保持控制台进程和电脑运行即可，无须保持网页打开。[轮换配置说明](docs/console-guide.md#区服轮换挂机)

运行状态按各玩法显示检查结果与执行条件，博物馆探宝和海兽培育的总开关汇总各自子项的计划。

礼包兑换支持批量选择账号，在账号列表查看兑换进度和最近一批结果汇总。后台按账号防重复兑换，成功、已用或结果未知的码不会重发。

世界概览与硅矿概览的联盟名称使用同一规则：优先显示自定义名称，名称为空或摘要不可用时显示当前场景的主城默认名，两者都无法匹配时才提示名称未同步。硅矿浮层中的默认名称带有来源提示。[硅矿概览与快捷操作](docs/silicon-automation.md#总览中的硅矿概览)

各玩法的默认开关、资源限制、调度顺序与确认方式保存在使用指南。[完整功能与规则](docs/console-guide.md#功能一览)

**挂机配置 → 英雄 → 英雄养成** 按账号选择培养名单、英雄养成动作与资源限制，留空即暂停培养；技能展示领奖覆盖所有已拥有的英雄，不受名单限制。装备和徽章强化在 **挂机配置 → 装备** 中设置，沿用指定英雄名单。[指定英雄养成](docs/console-guide.md#指定英雄养成)

**杂项 → 英雄与装备 → 英雄任命** 提供自动委任开关，默认关闭。开启后随自动挂机按游戏规则分配英雄。委任优先级支持拖拽和上下移动，越靠上越优先，七类效果顺序按账号自动保存。默认顺序为生产时间减少、训练营产量提高、贸易时间减少、建造速度提高、种田时间减少、海兽培育速度提高、锻造时间减少。

主导航的 **阵容** 页包含“我的阵容”和“推荐阵容”。在“我的阵容”中可新建自定义阵容，通过弹窗查看或编辑英雄站位、阵型与出战海兽。布阵使用游戏背景、头像和阵型图标，支持点选及拖拽。挑战页可为主线和各试炼选择已保存阵容并查看详情，挂机阵容在 **挂机配置 → 推关与试炼** 的对应项目中选择并自动保存。每场挑战完成后恢复开战前的游戏搭配，断线时保留恢复记录。[保存阵容与临时切换](docs/console-guide.md#保存阵容与临时切换)

不差钱商人的状态、订单材料、单次操作和全部活动开关统一位于 **活动 → 不差钱商人**。在活动详情中设置自动完成订单、缺材料时允许消耗钻石、自动领取最终奖励，修改后按账号自动保存。活动未开放、账号未连接或暂停时也能配置，已有选择会继续使用。自动完成与钻石补料默认关闭，钻石消费受全局总开关、每日预算和保留量限制。

联盟商船作为限时活动，全部开关和上船策略统一位于 **活动 → 联盟商船**，修改后按账号自动保存。未开放、未连接或暂停时可预先配置，已有选择继续使用；仅由活动页的本活动开关控制，挂机运行期间到达服务端开放时间即自动参与，按游戏规则在活动结束前 10 分钟停止申请船长、补货和新增红船备料，已发送申请仍继续核对结果；不依赖联盟自动化总开关。

超凡英雄在活动页归入周期活动，总开关、自动挑战、战败重试次数、自动完成订单、自动转盘抽奖和达标奖励统一位于 **活动 → 超凡英雄活动**。设置按账号自动保存，已有选择继续使用。重试默认 10 次，自动挑战与转盘默认关闭，转盘消耗已有英雄副本抽卡券。

海商王归入周期活动，自动走商、领奖、情报共享、采购策略、指针加速与补购、利润上限、首趟时间和商船升级统一位于 **活动 → 海商王**，修改按账号自动保存。未开放、未连接或暂停时可预先配置，原有参数和开关继续使用。购买指针和升级商船同时受全局钻石开关、预算及保留量限制。

活动页展示服务端已下发的起止时间，未开放与已结束的期次默认收起，并按账号保存历史。超凡英雄、不差钱商人、海商王的预配置入口归入“未开放活动”，展开后可编辑，读取到开放期次后自动移到上方。已开启的任务随挂机按主活动、子活动的有效时间自动启停，复开时继续使用保存的选择。未来日程取决于服务端下发范围，历史从实际读取后开始留存。

建筑一览提供需求联合排产，读取当前订单、已开启的消费备料、库存及生产队列，按用户设置的需求优先级逐级优化齐套时间。上游材料继承需求优先级，共享设备排队，独立设备并行，结果展示分层工期上下界、逐批投料与最优性证明状态。[需求联合排产](docs/console-guide.md#需求联合排产)

城战支持逐队设置进攻或防守，并独立设置两侧的目标来源、城市名单和优先策略。[城战攻守目标](docs/console-guide.md#世界与挑战)

广告任务各入口默认关闭。有免广告权益时立即领取，已开启的任务也支持无权益账号等待后直接领奖。无权益流程存在服务器识别和账号处罚风险，启用前请阅读具体说明与已有验证范围。[广告奖励](docs/console-guide.md#广告奖励)

## 配置与预算

- 挂机配置按账号自动保存。持续挂机会保存自动恢复选择，异常中止后重新连接或重启程序时恢复运行。**暂停挂机** 会关闭自动恢复并保留连接，点击 **开始挂机** 后重新运行。**暂停托管** 会保存账号暂停状态，点击 **恢复托管** 后按已保存的间隔持续运行；旧的有限轮数配置不会限制网页开始或恢复的挂机。
- **钻石总开关默认关闭**，每日总预算默认 `2000`，钻石保留阈值默认 `0`。日预算为 `0` 时禁止自动花钻石，各项目限制与总预算同时生效。
- 发送前先占用预算。明确未发送或被拒绝时释放，结果未知时保留额度与防重记录，后续读取业务证据后确认。重启或保存配置不会清空未知记录。
- 材料、金币和舰队预留与持久账本配合。配置保存在 `data/automation-settings.json`，用量与防重记录保存在 `data/automation-usage.json`，按北京时间零点换日。
- 旧版挂机配置会自动迁移，保留已有开关和参数。配置格式编号较高时也先尝试按内容兼容，校验通过即可正常读取、保存和挂机，保存不会降低已有版本号；只有未知字段、非法值或无法无损保留的设置才会阻止兼容，并显示具体原因、保留原文件。

旧配置兼容、订单预留、玩法开关及活动恢复规则见使用指南。[配置与预算细则](docs/console-guide.md#配置与预算)

## 数据与问题排查

- `data/` 包含账号凭据、设置、账本和日志。账号页支持导入备份，单账号和全部账号均可选择“仅账号”或“账号及配置”导出；导入按渠道和账号合并，新账号不会自动挂机。配置页单独导出只包含玩法设置，账号导出包含登录凭据，两者均不包含用量账本。
- `work/` 保存本机协议、配置与素材缓存。`certificates/` 保存抓包证书与代理备份，采集恢复记录保存在 `data/capture-session.json`。
- 控制台只监听 `127.0.0.1`，没有登录校验。手机访问需自行搭建带鉴权的隧道。
- 异常退出后，启动自检会提示上次采集残留。可在账号页恢复，或运行下表的 `recover` 命令。

遇到功能未执行或持续待确认，请先保留 `protocol.log` 和 `protocol.log.1`，结合发生时间、配置与实际结果反馈。协议解码失败会在 `data/protocol-errors/` 独立保存 JSON 快照，普通日志轮转不会覆盖这些快照；网页和终端会保留无法识别的消息名称。快照包括消息名、序号、当时等待的请求、近期报文头和收到帧的十六进制内容，单帧最多保留 256 KiB，超限标记截断，最多保留 100 份；登录阶段、认证类报文及报文头无效的畸形帧不记录原始内容。完整排查步骤和附件要求见使用指南。[问题反馈日志](docs/console-guide.md#问题反馈日志)

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm start` | 构建界面并启动控制台，默认端口 `17321` |
| `.\start-console.cmd` | 使用 Node 启动入口，端口 `17323`，输出地址与实时日志 |
| `node tools/start-console.mjs` | 直接使用上述启动入口 |
| `.\start-console.cmd status` | 检查抓包证书和上次采集恢复记录 |
| `.\start-console.cmd recover` | 恢复上次采集留下的代理和证书改动 |
| `npm run build:ui` | 重新构建控制台页面与样式 |
| `npm run test:offline` | 运行无需本机游戏协议包的核心回归 |
| `npm run typecheck` | 检查全部 UI TS/TSX、持久化与用量账本的类型约束 |
| `npm run check:ui` | 使用 Biome 检查已迁移客户端代码与配套测试 |
| `npm run test:client:browser` | 使用隔离账号验收账号卡片登录设置、独立保存和草稿隔离 |
| `npm test` | 构建界面并运行全部回归，包含真实协议编解码验证 |
| `npm run sync-resources` | 立即检查并更新配置表和世界地图 |

完整 `npm test` 需要本机游戏协议包。可先在电脑版微信中打开游戏，或设置 `CW_PROTO_BUNDLE` 指向自己的 `_src_chunks_.wxapkg` 或解包后的 `game.js`。离线回归使用显式测试数据，真实协议回归继续检查当前游戏包兼容性。

端口、浏览器、资源更新间隔和其他开发命令见使用指南。[启动参数](docs/console-guide.md#启动参数) · [资源自动更新](docs/console-guide.md#资源自动更新) · [开发与辅助命令](docs/console-guide.md#开发与辅助命令)
